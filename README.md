# 🎮 Văn Phòng Kỳ Hiệp (Office Legend 2D RPG)

Game 2D nhập vai học Tin học Văn phòng tương tác trực tiếp trên trình duyệt web:
- **Phím tắt**: Windows & Office Shortcuts Battle
- **Word**: Soạn thảo văn bản chuẩn thể thức Nghị định 30/2020/NĐ-CP
- **Excel**: Thực hành các hàm SUM, AVERAGE, IF, VLOOKUP trên bảng tính tương tác
- **PowerPoint**: Kỹ thuật trình chiếu và quy tắc thuyết trình chuyên nghiệp
